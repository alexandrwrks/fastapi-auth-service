# Frontend для FastAPI Auth Service

## Описание

Простой и минималистичный фронтенд для сервиса аутентификации на основе FastAPI.

### Возможности

- ✅ Регистрация новых пользователей
- ✅ Вход в систему
- ✅ Просмотр профиля
- ✅ Простая админ-панель
- ✅ Безопасное хранение JWT токенов в localStorage
- ✅ Автоматическое обновление токенов
- ✅ Чистый, красивый интерфейс
- ✅ Минимальный JS код (только необходимая функциональность)

## Установка и запуск

### Требования

- Python 3.11+
- Docker (опционально для БД)
- Web-browser

### Шаги

1. **Запустите backend:**

```bash
# Установите зависимости
pip install -r requirements.txt

# Настройте .env файл (если необходимо)
# DATABASE_URL, SECRET_KEY и другие параметры

# Запустите приложение
python -m app.main
```

Бэкенд будет доступен на `http://localhost:8000`

2. **Откройте frontend:**

Просто откройте файл `frontend/index.html` в браузере или используйте локальный веб-сервер:

```bash
# Если у вас есть Python
python -m http.server 8080 --directory frontend
```

И откройте `http://localhost:8080` в браузере.

## Функциональность

### Страницы

1. **Главная (Home)** - Приветственная страница с кнопками входа/регистрации
2. **Регистрация** - Форма регистрации нового пользователя
3. **Вход** - Форма входа
4. **Профиль** - Просмотр информации текущего пользователя (доступна после входа)
5. **Админ-панель** - Просмотр списка всех пользователей (доступна администраторам)

### Управление токенами

Токены хранятся в `localStorage` браузера:
- `accessToken` - используется для аутентификации запросов
- `refreshToken` - используется для обновления accessToken

При истечении accessToken приложение автоматически пытается его обновить.

## API Endpoints (требуемые)

Бэкенд должен предоставлять следующие endpoints:

```
POST   /auth_service/register     - Регистрация
POST   /auth_service/login        - Вход
POST   /auth_service/refresh      - Обновление токена
POST   /auth_service/logout       - Выход
GET    /auth_service/me           - Получить текущего пользователя
GET    /admin_service/users       - Получить список пользователей (только для админов)
```

## CORS

Если фронтенд и бэкенд на разных портах, убедитесь что backend настроен на CORS:

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # или конкретные домены
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

## Технологии

- **HTML5** - структура
- **CSS3** - стили (без фреймворков, только чистый CSS)
- **Vanilla JavaScript** - логика (без React, Vue или других фреймворков)
- **localStorage API** - хранение токенов

## Примечания

- Фронтенд полностью клиентский, не требует сборки (build)
- Можно запустить на любом веб-сервере
- Все данные отправляются на бэкенд, фронтенд только отображает
- JavaScript минимален - только для управления токенами и навигацией

## Безопасность

- ✅ Использует HTTPS для защиты (в production)
- ✅ Не хранит пароли на клиенте
- ✅ Очищает токены при выходе
- ✅ Валидирует все входные данные на бэкенде
- ✅ Защита от XSS через escapeHtml функцию
